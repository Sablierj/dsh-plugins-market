# 关键词总库 A+B 组：趋势与落位处方（2026-10-21）

> 需求方批准"按你的思路优化"，并追问转化数据 / 出单数据 / 品牌旗舰店数据要不要考虑。
> 这份文档记录：为什么要这两组字段、规则是什么、实测效果、以及那三种数据的口径结论。

---

## 一、为什么是这两组

| 问题 | 改前 | 改后 |
|---|---|---|
| 这个词在涨还是在跌？ | 答不了（主表只留最新一期） | `trend_json` |
| 抢到了写在哪、第几档？ | 只有六个布尔"能不能写" | `placement_json` |

**数据证据**：ABA 事实表已有 7 个周期（2025-Q1…2026-03），其中 **2,596 个词有 ≥2 期、
1,696 个词有 ≥3 期** —— 趋势一直算得出来，只是从没算过。

## 二、`trend_json`

```json
{
  "trend": "rising",
  "periods": 7,
  "latest": "2026-03", "previous": "2026-02",
  "svLatest": 33250, "svPrev": 31835,
  "momPct": 4.4,
  "avg": 53713,
  "basis": { "thresholdPct": 15, "periodsUsed": ["2025-Q1", …] }
}
```

**规则**：
- 周期折成同一时间轴：季报 `2025-Q4` → 202512、月报 `2026-03` → 202603
- 环比只与**紧邻前一期**比；**季报与月报不混算**（一个季度抵三个月，混算会把 Q4→1 月当普通环比）
- ±15% 以外才算涨/跌，以内算平
- 四种"没有趋势"分开说：`insufficient`（没有历史）/ `single-period`（只有一期）/ 涨 / 跌 / 平

**实测分布**：insufficient 18,851 · single-period 9,331 · falling 1,089 · rising 1,017 · flat 490

## 三、`placement_json`

```json
{ "slot": "title", "tier": 2, "form": "exact",
  "reason": "身份词 + 搜索量 33250 + L3 —— 够格进标题" }
```

**规则**（与 SOP §6.1–6.4 一致，不外扩）：

| 角色 | 搜索量 | 层级 | 落位 | 档 |
|---|---|---|---|---|
| identity | ≥10,000 | ≤L3 | 标题 | ≥5 万→1，≥2 万→2，其余→3 |
| identity | ≥1,000 | ≤L4 | 五点 | ≥2 万→1，≥5 千→2，其余→3 |
| identity | 其余 | — | 后台 | 3 |
| 非 identity | 任意 | — | **不落位** | — |

**明确不做**：不判重（`bench cushion` vs `bench cushions` 要跨词比较）、不改写词（生成的新词没人审过）。

**实测分布**：title 44 · bullets 218 · backend 15,804 · 不落位 14,712

## 五、那三种数据的口径结论

### ① 转化数据：要考虑，但它有三层，不能相加

| 层 | 来源 | 现在有吗 |
|---|---|---|
| 市场购买率 | ABA 购买量总数 ÷ 点击总数 | ✅ 可算（1.89% 那类） |
| **我们品牌购买占比** | ABA 购买量：品牌占比% | ✅ 7.547% |
| 广告 CVR | 广告报告 订单÷点击 | ✅ 95% 填充 |
| **加购率** | ABA 购物车加入：加购率% / 品牌占比% | ❌ **有数据、没入库** ← 最该补 |

加购是**诊断"临门一脚"的那一层**：加购高、购买低 = 价格/运费/评价问题；加购低、曝光高 = 主图/标题问题。

### ② 出单数据：一份真、一份估

- **ABA 品牌购买量**（本例 16）= 我们品牌在该搜索词上的购买数 —— **事实**
- **广告订单** = 只算广告位
- **自然单 ≈ 品牌购买量 − 广告订单** —— 可做，但 ABA 与广告的归因窗口不同，**必须标成估算**

不能把这两者放进同一个字段名。

### ③ 品牌旗舰店数据：只能到店铺级

品牌分析给的是店铺销售额与流量来源（搜索/外部/直达），**没有"哪个词带来多少"**。
正确用法是**当基准**：店铺转化 3%、某词 1.89% → 这个词偏低值得单独看；但**不能**说"这个词贡献店铺 5% 销售"。

结论：可以接一张"店铺基准"卡，**不进 `kw_master`**。

## 六、这份改动没有解决什么

- **判重没做**：单复数冲突仍要人工看
- **加购没入库**：需要在 ABA 解析器里加 4 列并重导 7 个文件
- **自然单估算没做**：依赖加购那一批
- **增量重算没做**：现在仍是全量 30,778 行重算
