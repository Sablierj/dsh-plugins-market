# 运营运用方案（运营 / 数据分析 / 关键词研究 / 市场分析）

> 前提：数据已经按 [`02-数据存放方案`](02-数据存放方案.md) 落库。**所有结论必须能回指一行数据**（`sif_insight.evidence_json`），不接受「感觉最近流量不行」。

## 1. 四类角色，四种问题，四张表

| 角色 | 只回答一个问题 | 主要读 | 触发点 |
|---|---|---|---|
| **运营** | 今天/本周该动手做什么？ | `v_traffic_last8w`、`v_ad_dependency`、`sif_sales_month` | 每天 10 分钟 |
| **数据分析师** | 这个变化是真的还是噪声？ | `sif_traffic`（周/日序列）、`sif_asin_snapshot` | 出现拐点时 |
| **关键词研究员** | 该抢哪个词、放弃哪个词？ | `sif_keyword_aba`、`sif_asin_keyword`、`sif_keyword_demand` | 每周 + 上新前 |
| **市场分析师** | 这个赛道/竞品值不值得打？ | `sif_competitor`、`market_*` 三件套、`sif_keyword_demand.seasonality` | 选品/季度规划 |

## 2. 固定节拍（把点数花在节拍上，不要花在闲聊上）

| 周期 | 动作 | 用到的 MCP 工具 | 点数 |
|---|---|---|---|
| **每天** | L1 落数 → 看板扫一遍：谁的自然分掉了、谁广告占比破了 60% | `ops_get_asin_traffic_trend` + `ops_get_listing_traffic_overview` | 5/ASIN |
| **每周一** | L2 落数 → 三件事：头词位置、缺口词、广告结构变化 | `keyword_signals` + `ad_structure` + `sales_trend` | 6/ASIN |
| **每月** | 关键词体检：ABA 增量 + 需求诊断 + 竞争格局 | `keyword_history` + `keyword_demand` + `keyword_competition` | 5/词 |
| **按需** | 流量掉了要归因 | `analyze_traffic_anomaly` | 10/次 |
| **上新前** | 赛道三问：有多少量 / 打得过吗 / 打得过能不能赚 | `market_get_keyword_root_trend` → `competition` → `assess_keyword_promotion` | 3+2+1~4 |

## 3. 判定阈值表（写死在规则引擎里，页面和模型共用）

| 规则 | 条件 | 结论 | 建议动作 |
|---|---|---|---|
| **缺口** | 自然位在第 2 页及以后 **且** 该词流量占比 ≥ 5% | 差 N 位进首页 | 该词单独开精确/词组，预算按份额配；优先修 Listing 相关性与转化 |
| **广告依赖** | 近 4 周中 ≥2 周 `ad_ratio ≥ 0.6` **且** 自然分环比下滑 | 流量靠钱撑着 | 不要加预算，先补自然位；查 SB/SP 是否在替自然位打工 |
| **真下滑** | 连续 2 周 total 环比 ≤ -25% **且** 自然分同步跌 | 不是季节，是丢了位置 | 触发 `analyze_traffic_anomaly`（10 点）做归因 |
| **假下滑** | total 跌但自然分平/涨，且 ABA 周量平 | 广告停了，不是产品坏了 | 只查广告结构，别动 Listing |
| **结构性下滑** | 需求诊断 = 结构性下滑（年均 decay < 0）**且** 季节位置=谷 | 市场在缩 | 该词止损，量转投上升词 |
| **集中悖论** | `top3_click_share` 高 但 `top3_conversion_share` 低 | Top3 锁点击没锁转化 | 强产品可切；弱产品别硬冲 |
| **旺季窗口** | `weeks_to_peak ≤ 8` 且 diagnosis 健康 | 该提前铺货/铺词 | 现在布局自然位，旺季收割 |

阈值是可配参数（`config.rules`），不是硬编码在页面里——因为不同类目的波动幅度天然不同。

## 4. 实战：B0XXXXXXXX（数据来自本次真实拉取）

**基本面**：$44.59、4.5 星 / 49 评、2026-01-27 上架、11 个变体、Patio Furniture Cushions 类目 BSR 317。

**流量（近 10 周，周粒度）**
- 10-25 那周冲到 3039 分（广告占 **80.4%**），11-01 掉到 976（**-67.9%**）——同一周广告分从 2443 掉到 592，自然分只从 596 掉到 384。
- 结论：**这次下跌是广告刹车，不是自然位崩**。近 10 周里有 3 周 `ad_ratio ≥ 0.6`。
- 这正好是「假下滑」模板：先查广告结构，别急着改 Listing。

**关键词（85 个词里最要紧的三个）**

| 词 | 流量占比 | 自然位 | SP | 判定 |
|---|---|---|---|---|
| `rocking chair cushions` | **43.8%** | p2, 11/48 | 无 | 缺口 severe：差 11 位进首页，且它是第一大流量来源 |
| `rocking chair cushions indoor` | 16.3% | p3, 5/48 | p3, 12/12 | 缺口 severe：自然+广告都在第 3 页 |
| `glider rocker replacement cushions` | 7.5% | p2, 21/48 | 无 | 该词本身**结构性下滑**（年均 -20%），是止损候选，不是冲刺候选 |

**ABA 需求（`rocking chair cushions`，320 周历史）**
- 周量 9631（截至 10-25），年度脚印：2021→2022 **-49%**、2022→2023 -7%、2023→2024 -17%、2024→2025 -8%、2025→2026 **+206%**。当前是「长期跌完、今年反弹」的健康增长。
- 季节：峰 3/10/1 月，谷 12/4/6 月，`weeks_to_peak = 20` → **现在离旺季还有 20 周，正是铺自然位最便宜的时候**。
- Top3 点击 25.4% / Top3 转化 9.3%：点击不算垄断，转化更松 —— 属于「可以挤进去」的格局。

**广告结构**：23 个 campaign（SP 19 / SB 4 / SBV 0）。SBV 为 0 说明视频广告位是空的，这是现成的增量位。

**四条动作（按性价比排序）**
1. `rocking chair cushions` 单独精确/词组，把 p2 → p1 的 11 位打成 KPI（它一人占 43.8% 流量）。
2. `glider rocker replacement cushions` 预算撤到 30%，转投上升词；该词只保留词根卡位。
3. 补 SBV 视频位（当前 0 个 campaign 在跑视频位），成本最低的曝光增量。
4. 11 月是旺季前最后一次铺货窗口（`weeks_to_peak=20`），库存与评价要在 3 月前到位。

## 5. 报告三件套（都由 `sif_report` 生成，模板固定）

**日报（5 段，≤ 1 屏）**：数据截止日 → 流量总分与自然/广告占比 → 与上周/上周均线对比 → 触发阈值的事件 → 今日待办 1-3 条。

**周报（7 段）**：① 一句话结论（排除式，如「本周跌的不是自然位，是广告预算」）② 流量结构表 ③ 头词位置变化表 ④ 缺口词清单（份额 × 差几位）⑤ 广告结构变化（campaign 增删）⑥ 需求侧（ABA 周量、季节位置）⑦ 下周动作与各自的数据依据。

**专项报告（广告复盘 / 词研究 / 赛道评估）**：结论 → 证据（表/图）→ 反例排除（「如果只是季节性，那么应该……但数据显示……」）→ 残余不确定性（还缺哪张表才能判死）→ 动作。

## 6. 什么时候**不该**用 SIF MCP

它给的是流量、广告、关键词、市场四域的结构化数据，**不给 Listing 文本级的答案**：

| 问题 | 该用谁 |
|---|---|
| 标题/五点怎么写、埋哪些词 | amazon-ops（Listing 库 + 优化草案） |
| 竞品页面的变体结构、A+、图片 | amazon-ops 的 CDP 采集 |
| 库存/退货/客诉 | 卖家后台，本仓没有来源 |
| 我的转化率、ACOS 真实值 | 广告后台，SIF 只有估算与相对分 |
| 「为什么这个词掉了」 | 先用本地 ABA + ASIN×关键词判，判不动再花 10 点调 `analyze_traffic_anomaly` |

**边界要说出来**：SIF 的 `score`、`share`、`contri_change` 都是**相对量**，任何「涨了 X%」的说法都必须先确认它是绝对值还是份额。库里把这点拆成了列名（`_score` / `_ratio` / `contri_change`），页面也按此标注。

## 7. 一个闭环的样子

```
周一 09:00  L2 同步（6 点/ASIN）            → sif_traffic / sif_asin_keyword / sif_ad_campaign 更新
周一 09:05  规则引擎跑 5 条洞察              → sif_insight 出现 3 条 high
周一 09:10  看板：缺口 severe 的词占 43.8%   → 人决定「本周主攻这个词」
周二-周日   运营执行（改广告/改 Listing）     → 在 amazon-ops 里做，登记
下周一 09:00 同一张表再看：p2,11 → p2,3？     → 自然分是否跟着涨 → sif_insight 关单或继续
```

每一环都留在本地库里，所以「上个月这个决定到底有没有效」是可回答的，而不是凭记忆。
