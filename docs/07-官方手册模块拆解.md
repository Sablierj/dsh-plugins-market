## 一句话结论

五份手册不是五份资料，而是**同一条能力曲线的五个切面**：初阶解决「能不能调起来」，中阶解决「调起来能问什么」，高阶把中阶的原子场景串成 4 条自动判断链，两份专项手册则各给了一条**带输出契约的作业模板**（新品立项 / 存量改标题）。

## 二、逐份模块拆解

### 2.1 初阶版（6 模块 = 接入通路）

| # | 模块 | 作用 |
|---|---|---|
| 1 | 前景提要 | 为什么需要 MCP（把网站数据接进 AI 对话） |
| 2 | Sif MCP 背景介绍 | 能力边界与产品定位 |
| 3 | 使用前准备 | 账号、密钥、配额、安装前置 |
| 4 | AI 客户端推荐设置 | 模型选择、上下文、工具白名单 |
| 5 | 开发同学视角 | MCP 配置、鉴权、调试排错 |
| 6 | 运营同学视角 | 怎么提问、怎么读结论 |
| 7 | 常见 FAQ | 卡点兜底 |

> 本质是「装得上 + 问得出」，不含判断口径。

### 2.2 中阶版（4 Part + 1 特色模块 = 场景原子库）

**Part 1 关键词与需求发现（5 场景 + 场景能力地图）**

| # | 场景 | 解决的问题 |
|---|---|---|
| 1 | 关键词机会筛选 | 一个词根下，哪些词更值得先研究 |
| 2 | 词根市场规模判断 | 精确词背后的盘子有多大 |
| 3 | 精确词与长尾需求分布 | 需求集中在精确词还是散在长尾 |
| 4 | 关键词需求生命周期 | 增长 / 稳定 / 回暖 / 衰退 |
| 5 | 新品入场时机 | 该进入、准备、放量还是暂缓 |

链路：机会词 → 市场规模 → 需求分布 → 生命周期 → 入场时机 → 进入竞争分析

**Part 2 市场竞争与竞品筛选（6 场景 + 场景能力地图）**

| # | 场景 | 解决的问题 |
|---|---|---|
| 1 | 关键词竞争可进入性 | 流量入口是否被头部锁死 |
| 2 | Top 100 竞品格局扫描 | 销量/评论/价格带的分布 |
| 3 | 低门槛竞品筛选 | 按价格、评论、姿态收敛 |
| 4 | 词根头部竞品识别 | 谁是真正的市场领导者 |
| 5 | 核心竞品产品画像拆解 | 对标品是什么规格、什么产品 |
| 6 | ASIN ABA 卡位地图 | 某 ASIN 靠哪些词吃饭、卡在什么位 |

链路：竞争判断 → Top100 格局 → 条件收敛 → 识别领导者 → 拆产品画像 → 进入 Listing 定位

**特色模块：推广成本与利润测算（2 场景）**

| # | 场景 | 解决的问题 |
|---|---|---|
| 1 | 关键词推广可行性与投放模式 | CPC/CVR 能否支撑投放、走什么投放模式 |
| 2 | 利润阈值与采购成本上限倒推 | 扣佣金/FBA/头程/目标利润后，采购价能到多少 |

链路：机会词 → CPC/CVR → 投放模式 → 盈亏门槛 → 尺寸重量 → FBA 与佣金 → 采购上限

**Part 3 产品与 Listing 定位 / Part 4 广告结构与投放拆解 / Part 5 上线后诊断**
→ 网页版**只有标题、没有正文与子场景**（见文末）。

### 2.3 高阶 Skill 版（4 条纵向自动链）

| # | Skill | 串起来的是什么 |
|---|---|---|
| 01 | 市场机会 × 产品可行性 | 中阶 Part1 + 特色模块 1：值不值得做、从什么词切 |
| 02 | 竞品流量 × 广告策略解剖 | 中阶 Part2 + Part4（广告）：竞品靠什么词、什么流量、什么广告结构 |
| 03 | 产品利润 × 推广经济模型 | 特色模块全量：采购红线、CPC 盈亏线、广告承受力 |
| 04 | 流量诊断 × 增长修复 | 中阶 Part5 + ads_*：定位下跌真因，下钻关键词/广告组/变体给修复动作 |

外加「MCP & 设置 Agent 流程」一节（怎么把 Skill 挂到 Agent 上）。

> 架构含义：**中阶是原子，高阶是编排**。21 个场景被归并成 4 条链，正好对上四个业务动作：要不要做 → 抄谁 → 怎么算得过来 → 掉了怎么救。

### 2.4 市场调研五阶段提示词（决策链模板）

| 阶段 | 回答什么 | 关键约束 |
|---|---|---|
| 一、市场容量 | 这个方向有没有盘子 | 一次只吃一个站点 + 一个非品牌词 |
| 二、竞争格局 | 普通款的竞争门槛 | 判断能不能挤进去 |
| 三、长尾需求与细分入口 | 从长尾里找细分入口 | **必须由用户选一个方向**再往下 |
| 四、细分市场与对标竞品验证 | 选定方向的对标品与利润参照 | 限制工具调用范围 |
| 五、利润与关键词推广经济性 | 采购红线、推广经济性 | 需要补成本输入 |

外加三层：最终可视化报告提示词、点数控制与推荐调用链、8 条口径纪律（市场容量不是一个数字 / 词根市场≠单一产品市场 / 低集中度≠低门槛 / 长尾词≠产品定义 / ASIN 尺寸口径要核对 / 基础贡献利润≠净利 / 推广经济性用市场参考值 / 建议保持克制）。

> **这条手册最有价值的一点**：它把「不要一次提交全部提示词」写成硬约束——分阶段才能中途纠偏、控制点数。这等于给了插件一个设计原则：**阶段门比一把梭重要**。

### 2.5 标题新规修改报告（输出契约模板）

**输入 4 项**：ASIN（实际要改的子 ASIN，变体不混做）、站点、SIF MCP 可调（先 ping）、商品资料截图（可选，用于确认尺寸/材质/适配/包装）。

**输出 4 模块**：

| 模块 | 内容 |
|---|---|
| 核心结论 | 两列对比：标题、亮点、五点、监控、广告建议 |
| 优先级表 | 拆解原标题词组 × 类型 × 关键词对应 × 流量 × 排名 × 趋势 × 优先级 × 最终去向 |
| 四个动作 | 标题修改 / 亮点新增 / 五点方向稿 / 上线监控与广告承接 |
| 透明度声明 | 实际用了哪些工具、数据周期、资料完整度、缺失字段、待确认事实、AI 建议边界 |

> **透明度声明是这份手册的杀手锏**：它把「AI 的结论边界」变成报告里的一节，而不是藏在免责声明里。任何对外交付的 AI 报告都该抄这一节。

## 三、四份手册共通的四条方法论

1. **先排除、再结论**：中阶明说「同一个现象可能由多个原因造成」，先列可能的归因，再逐个用工具排除。
2. **每步都声明「能确认什么 / 不能确认什么」**：这是官方反复强调的写法，也是防幻觉的结构性手段。
3. **口径写在前面**：CTR 是整体搜索点击率不是 Top3 集中度、搜索量是周不是月、销量是前台档位不是精确值——一句话错口径，整份报告作废。
4. **分阶段、控点数**：既是成本纪律，也是质量纪律（中途可纠偏）。

已实现的 11 个工具：`sif_status` / `sif_sync` / `sif_dashboard` / `sif_query_traffic` / `sif_keywords` / `sif_mine` / `sif_competition` / `sif_actions` / `sif_health` / `sif_report` / `sif_listing_audit`。

| 手册模块 | 现有对应 | 状态 |
|---|---|---|
| 初阶：接入与配置 | `sif_status` + 设置页 | ✅ 覆盖 |
| Part1-1/2/3 机会词、规模、分布 | `sif_mine` + `sif_keywords` | ✅ 覆盖 |
| Part1-4 需求生命周期 | `sif_keywords`（诊断/动量字段） | 🟡 有数据，缺「阶段性结论」 |
| Part1-5 入场时机 | `sif_actions`（部分） | 🟡 部分 |
| Part2-1 竞争可进入性 | `sif_competition` | ✅ 覆盖 |
| Part2-2/3/4/5 Top100 / 低门槛 / 领导者 / 画像 | `sif_competition` + MCP `market_discover_competitors` | 🟡 只存了 top 竞品，没有四维格局与画像落库 |
| Part2-6 ABA 卡位地图 | MCP `market_get_asin_aba_footprint` | ❌ 插件未接 |
| 特色模块 利润与采购上限 | MCP `market_estimate_profit_threshold` | ❌ 插件未接（高价值缺口） |
| Part3 产品与 Listing 定位 | `sif_listing_audit` + M12/M13 | ✅ 覆盖 |
| **Part4 广告结构与投放拆解** | `ads_*` 12 个 MCP 工具 | ❌ **插件零覆盖** |
| **Part5 上线后诊断闭环** | 只有一次性报告 | ❌ 缺「观测节点 + 复测对比」闭环 |
| 高阶 4 Skill 编排 | 无 | ❌ 全是单点工具，无编排层 |
| 五阶段提示词 | `sif_report` 单份报告 | 🟡 缺分阶段状态机与点数预算 |
| 标题新规报告 | M13 草稿 + `sif_listing_audit` | 🟡 缺「优先级表 + 透明度声明」两块 |

**三个真正的缺口**（按投入产出排序）：
1. **广告结构域**（Part4 + 高阶 02 + 04）：SIF 侧 12 个 ads 工具，插件侧 0 个模块——数据和能力都有，只是没接。
2. **利润与推广经济模型**（特色模块 + 高阶 03）：两个 MCP 工具即可成模块，直接决定「能不能赚钱」，最容易被运营追问。
3. **观测闭环**（Part5 + 高阶 04）：报告发完就结束，没有 7/14/30 天的节点对比，无法证明优化有效。
