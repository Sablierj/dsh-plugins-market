## 附：为什么必须重启（机制层面，不是习惯）

`src/web/page.js:99-104` 是这样拿页面片段的：

```js
import { kwScript } from './pages/kw.js'
import { competitorScript } from './pages/competitor.js'
...
```

**ESM 的 import 在加载时求值一次，之后缓存在模块图里。**
同理 `index.js` 的 `buildTools()` 也只在 `apply()` 时跑一次。

所以运行中的插件用的是**启动那一刻**的代码：

| 你看到的 | 用的是哪份代码 |
|---|---|
| 页面上的一切 | 启动时的 `pages/*.js` + `page.js` |
| 对话里调到的工具 | 启动时的 `src/tools/*.js` |
| `node tests/run.mjs` | **当前磁盘上的代码**（新进程） |
| `node -e "import(...)"` 这类 probe | **当前磁盘上的代码** |

**这就是今天最容易被混淆的一件事**：
我改完代码之后，用 probe 验的是**新代码**，用工具验的是**旧代码** ——
两边都「验过了」，但验的不是同一份。清单里每一步都注明了属于哪一边。

**今天 108 个源文件改了、schema 没动（v69）** —— 所以重启不需要迁移，只是让新代码进内存。
