### 4.3 你要写的那 3 行 —— 该断什么（写清判据，代码在你手里）

位置：`run.mjs` 的 kw 状态块里，`if (kwPayload.master.imports.length === 0) …` 那一段之后
（现在在 `10116` 附近，你的 `50504cd` 之后行号会变，按这段文字定位）。

要断**三件事**，一件都不能少：

```js
/* ① 字段到了没有：不透传 = 页面永远看到 0，上一轮 spend_missing 就是这么哑的。 */
if (!('rows_read_missing' in kwPayload.master.imports[0])) {
  throw new Error('the import slice dropped rows_read_missing — 未记录 会在页面上读成 0 行')
}
/* ② 真导入必须标记为「有行数」：夹具里的文件是真的词表，不是「没记到」。
     断 0 而不是断「非 1」—— 断「非 1」对 undefined 也成立，等于没断。 */
equal(kwPayload.master.imports[0].rows_read_missing, 0, 'a real import has a recorded row count: ')
/* ③ 同一条行的 rows_read 也得是数字（两列不许一个到、一个不到）。 */
equal(typeof kwPayload.master.imports[0].rows_read, 'number', 'the row count itself must be a number: ')
```

为什么是这三条而不是「断 `=== 1` 那条」：`/api/state` 的夹具文件是真的词表（有行数），
所以这里**只可能**看到 0；要看 1 得往库里塞一份「没记到」的导入行 —— 那会污染
`run.mjs` 里后面那些依赖 import 列表的断言（比如 `imports[0].id` 的排除/恢复）。
**「1 + 未记录」由 `t73m-②` 在独立 store 里断**，两处分工，不重复造数据。

### 5.4 六条铁律对照

| 铁律 | 这单怎么落 |
|---|---|
