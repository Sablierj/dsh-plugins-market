## 二、R-4（P1）「当前文案 (空)」是误导 —— **已修**

实测输出：

```
## 当前文案
来源 listing 表 · 版本 v1
**标题** (0 字符)
> (空)
```

而查库：
```
asin.title  = "Custom Size Bench Cushion, 75D High Density Foam Filling"
listing 行  = 1 行，但 title / bullets_json / description 全是 NULL
```

**商品页上有标题，本仓的 listing 表里没有。**

根因：采集只把标题写进 `asin` 表，**不写 `listing` 表**（`listing` 的唯一生产写入方是草案采纳）。
所以「listing 为空」和「商品页没有文案」是两件事，而输出把它们混成了一句「(空)」。

**后果**：运营看到「标题 (0 字符) (空)」会以为这个商品没有标题 → **去重写一个已经有的标题**。
这和我们打了一整天的「0 / 空 / 未测量」是同一类：**把「我没存」印成「它没有」**。

**修法**：listing 的标题为空、而 `asin.title` 有值时，多印三行：
> ⚠️ **本仓的 listing 表里没有标题 —— 但商品页上有。**（采集把标题写进 asin 表，不写 listing）
> `<真实标题>`
> 别把这条当成「标题是空的」去重写：listing 全文要人工从卖家后台导出，或等草案采纳后由本仓写入。

## 三、这一轮做对的地方（记下来，免得下轮重复查）

1. **位置计划**：「⚠️ **没有可继承的位置计划**：这个 ASIN 还没有位置计划 —— 08 里一行都没有」
   并明说 **「这与『计划里有 0 个位置』不是一件事」** —— 四态口径用在了计划上。
2. **策略卡九项**每项都带「来源」+「说明」，包括：
   - 「目标用户」：本仓**声明了字段但不存值**（类目属性要按 PTD 选），所以这项没有可读输入；
   - 「购买疑问」：本仓**没有 Q&A 数据源**，只能给「哪些搜索词长得像问题」；
   - 「风险待确认」：16 条**具名**清单（不是计数），其中 11 条是「只能由你判断」。
3. **关键词分配**：16 个词各一个主人（标题 1 / 五点 7 / 后台词 8），无冲突；
   并给出「⭐ 白拿的相关性（1 个）」——已经在排名但当前文案没写的词。
4. **字符预算**印「（没有可测量的字段）」而不是 0 —— 因为当前文案确实没有内容可量。
