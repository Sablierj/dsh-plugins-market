## 二、发现（按「运营会不会被卡住」排序）

### F-1 · 采集任务只印「时分」，没有日期 —— **P1，会让人误判**
采集页任务列表：`提交于 06:37 / 04:53 / 17:04 / 14:21`。
**没有日期。** 7 个任务跨了好几天（`274e08a6` 提交于 14:21、`f89f16b6` 提交于 06:37），
读起来像同一天发生的事。运营要靠这个判断「上次采是什么时候、是不是该重采」。

根因：`src/web/pages/asin.js:2568 taskClock()` 只 `slice(11,16)`，把日期丢了。
**同一函数还被用在别处**（`asin.js:2300` 的「提交于」），所以这是一处改动、两个页面受益。

### F-2 · 采集方案：默认写「全部 13 节」，唯一可用方案只覆盖 1 节 —— **P2，认知错位**
采集表单的「采集方案」默认项是 **「（全部 13 节）」**；
而下方方案表里唯一可用的 `AM-1 E2E 最小验证方案 v2` 写的是：
> 字段覆盖：BSR、类目与子类排名（**13 节中的 1 节**）

运营按默认提交，会以为在采 13 节，实际只采 1 节。**默认值必须与真实能力一致**：
要么默认选中那个真实方案并显示它覆盖 1 节，要么在没有「覆盖全部」的方案时**不提供**那个默认项。

### F-3 · ASIN 表：「点一行」同时是「选中」和「展开详情」 —— **P2，交互歧义**
同一页两句话：
- 表格下方：「点一行加入或移出选中」
- 详情区：「还没选中 ASIN：在上面那张表里点一行，这里就展开它的四页详情」

**同一个点击两个语义**。运营点一下，既改了全局选中集（影响其它页），又展开详情——想清空选中就得再点一次，而此时详情也收起来了。

### F-4 · 优化页不能选 ASIN，必须跨页往返 —— **P2，流程断点**
优化页的空态写：「还没有选中 ASIN。**在 ASIN 库里选一个产品**，这里就显示它的九项门槛」。
于是运营的动作是：优化页 → 跳 ASIN 库 → 点一行 → **跳回**优化页。
而且优化页把核心动作推给对话：「或直接在对话里说『对 B0… 跑一次 listing 优化』」——
**页面里能做的事，不该只能靠说话做。**

### F-5 · 3 万词的生命周期/产品线只能一条一条改 —— **P2，规模上跑不动**
关键词总库：`已设置 0 / 未设置 30,778`；`产品线未分类 3,386`。
生命周期面板写着「先在下面的表里点选**一条**词」。
**运营面对 3 万条、只支持单条操作**——这不是效率问题，是这条路走不通。
（所有权那部分**有**批量：勾选框 + 批量分配/释放/claim。缺的是**生命周期**与**产品线归属**的批量。）

## 五、决策（2026-10-25，需求方授权「你自己决策，按最优方案推进」）

| 项 | 决定 | 理由 |
|---|---|---|
| **F-1** | 今天印时分、不是今天印「月-日 时:分」 | 列表要紧凑，但不能丢日期；跨日误判的代价比一行长几个字符大得多 |
| **F-2** | **显示能力缺口，不用默认值掩盖**：没有覆盖全 13 节的方案时，「（全部 13 节）」置灰并说明 | 默认值让人以为系统就是这样设计的；缺口应该被看见 |
| **F-3** | **勾选框管多选；点行 = 展开详情 + 把上下文切到这一个 ASIN** | 多选与查看是两个意图，共用一个点击会互相打断。若下游只认多选集，则点行时**替换**选中集并在界面写明 |
| **F-5** | **做批量**（生命周期 + 产品线），all-or-nothing、上限 500、复用单条那套状态机 | 30,778 词只支持单条 = 这条路走不通；「跳过非法的写合法的」会让人以为全改了 |

### 为什么 F-3 不选「点行只选中」
那样「看详情」就得多一次点击或一个额外按钮，而**查看是列表页最高频的动作**；
且勾选框本来就只表达「我要对多条做事」，让它兼管「看哪一条」是把两个语义塞回一个控件。

## 六、第二轮走查（质量页 / 竞品页）

### F-6 · 「数据资产与质量」默认落在**数据目录**，运营要看的是**质量驾驶舱** —— P2
该页 6 个 tab：数据目录 / 质量驾驶舱 / 字段血缘 / 冲突工作台 / 快照管理 / 全局审计。
默认落在「数据目录」——那是一张**数据字典**（表 / 行数 / 主键 / 责任角色 / 空值含义 / 下游），
**受众是数据管家，不是运营**。运营点进来想问的是「我的数据哪里有问题」，那在第二个 tab。

> 决定：**默认 tab 改成「质量驾驶舱」**；数据目录保留（它是治理视图，有价值，只是不该当落地页）。

### F-7 · 关键动作只能「复制 prompt 去对话」——**跨页面的系统性问题**，P1
竞品页：「让 Agent 扫描这些词 … **这个按钮只复制 prompt，不自己跑**」；
优化页：「或直接在对话里说『对 B0… 跑一次 listing 优化』」。

**页面把实际动作交给对话，等于把工作流切成两半。** 文案是诚实的（明说只复制），
但运营要：复制 → 切窗口 → 粘贴 → 等回复 → 再切回来。这条不能靠改文案解决。

> 决定：记 **V-1 欠账（P1）**，方向是「页面能触发的动作，页面自己调工具」，不是继续加复制按钮。
> 优先级排在首页三件之后、批量操作之前。

### 竞品页做对的地方（记，免得下轮重复查）
- 「没导入过就是还没有数据 —— **那不是 0，是本仓没有可反查的竞品事实**」；
- 「竞品最好排名为空表示该词没有竞品排名，**不是 0** —— 0 会被读成排第一」；
- 「被丢掉的竞品就是没参与比较，而输出里不会有任何提示」——**解释了为什么无效 ASIN 直接报错**。
